PC Diagnostics Toolkit

A Python tool that explains what is slowing a PC down, spots likely hardware faults (failing drives, worn batteries, overheating) and recommends upgrades that would actually help, with free fixes listed first.

Screenshots (select one to open it full size):

Screenshots use the toolkit's built-in demo PC (example data, not a real machine).

How it works

You run one command, pcdiag scan, and the toolkit reads the PC's hardware and system data: CPU, memory, drives and their health, temperatures, battery, running processes and startup apps. A set of rules checks those readings for common problems and turns them into a verdict and a health score out of 100. It then writes an easy-to-read HTML report that lists free fixes first and ranks any upgrades worth buying by impact and cost. Anything it can't measure is shown as "Can't tell" instead of being guessed as healthy.

Key features

  • One-command scan of CPU, memory, drives, GPU, temperatures, battery and startup apps
  • Health score out of 100 with a plain-language verdict and 17 diagnostic checks
  • Self-contained HTML report (works in dark mode) plus raw JSON data
  • Free fixes first, then upgrades ranked by impact and cost
  • Optional speed benchmark, a compare command for before/after scans, and built-in demo PCs
  • Live monitoring and bottleneck analysis (in testing)

Built with:

  • Python
  • psutil
  • PowerShell (CIM)
  • HTML/CSS
  • pytest
  • GitHub Actions

Cooking with Cookie

A prototype website for a Nigerian food side hustle in Halifax, Nova Scotia, built as a portfolio project. Visitors can browse the menu, plan an order, ask about bulk orders for events and chat with Ask Cookie, a chatbot that answers questions about the food and shares recipes.

Screenshots (select one to open it full size):

Dish photos are placeholders until the owner's own food photos are added.

How it works

A Flask server in Python serves the website and a small JSON API from one address. The menu lives in an SQLite database, and the page loads the dishes, descriptions and likely allergens from the API when it opens. Ask Cookie answers with replies built from that same menu data, so every answer about a dish matches the menu. Ordering is in demo mode: the order summary counts the dishes picked, and customers place pickup or bulk orders by email or phone, not online.

Key features

  • Menu of 13 Nigerian dishes with quantity pickers and an order summary (demo mode, no online payment)
  • Ask Cookie chatbot for menu questions, ingredients, likely allergens and recipes
  • Allergen answers always flagged as unverified, with a cross-contamination warning
  • Bulk and event order enquiries, and a "Learn to Make It" recipe section
  • Prices switch: prices stay hidden until the owner turns them on
  • Responsive layout (3, 2 or 1 menu columns) and backend tests with pytest
  • Fried rice and grill choices, a Soups & Stews section and real food photos (coming soon)

Built with:

  • Python
  • Flask
  • SQLite
  • HTML/CSS
  • JavaScript
  • pytest

NetScope

A cross-platform Python command-line tool for network diagnostics: check whether a host is up, which ports are open, what a name resolves to, which routers are in the way, and whether a website is healthy, including when its TLS certificate expires. Results can be saved as JSON or HTML reports.

Screenshots (select one to open it full size):

Screenshots only check this computer (localhost) and local test servers.

How it works

Each command is a small Python module that returns a result object, which the command line prints as a table, as JSON or as a saved report. The port scanner opens a TCP connection to each port with a timeout and runs up to hundreds of checks at once in a thread pool, marking each port open, closed or filtered. Ping and traceroute run the operating system's own tools and read their output in several languages, so no administrator rights are needed, and ping falls back to timing TCP connections when ICMP is blocked. Before anything is sent, guard rails check the target and refuse large public ranges and your internet provider's address space.

Key features

  • Seven commands: ping, port scan, DNS lookup, traceroute, local network info, HTTP/TLS check and latency summary
  • Threaded TCP port scanner for a host, an IP or a small range, with service names and timing
  • HTTP checks with redirects, key headers, TLS version and days until the certificate expires
  • Table, JSON or saved HTML/JSON report output for every command
  • Runs on Windows, macOS and Linux with no required dependencies and no admin rights
  • 389 tests that never touch the internet, plus mypy type checks

Built for networks you own or are allowed to test.

Built with:

  • Python
  • Threads
  • pytest
  • mypy
  • CI on Linux, Windows & macOS
